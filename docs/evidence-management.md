# Evidence management

Evidence belongs to an exception and records type, title, original file name, opaque storage key, SHA-256 checksum, submitter, reviewer, timestamps, state, and notes. Local storage accepts PDF, PNG, JPEG, text, and CSV up to 10 MB. Files are not mounted into the web server or returned by arbitrary path. Rejection and clarification require a reason. Production hardening would add cloud object storage, encryption keys, malware scanning, retention/legal-hold rules, and time-limited authorized downloads.
